# Smart Parking System

A streamlined, end-to-end smart parking solution designed to monitor and manage parking space availability in real-time. The system uses hardware sensors for spot detection, a Python-based backend for processing data, and a mobile interface to help users easily find open parking spaces.

> **Note:** This project was developed and structured with the assistance of AI tools to accelerate the coding and design process.

## Technologies Used
* **Frontend:** Dart (Flutter)
* **Backend & ML:** Python
* **Hardware:** C++ (Arduino/ESP32)
* **Deployment:** Docker & Docker Compose

## Quick Start

**1. Clone the repository**
```bash
git clone [https://github.com/venkateshdhulipalla174-droid/smart_parking_system.git](https://github.com/venkateshdhulipalla174-droid/smart_parking_system.git)
cd smart_parking_system
```

**2. Start the backend services**
```bash
docker-compose up -d
```

**3. Run the frontend application**
```bash
cd frontend
flutter pub get
flutter run
```
